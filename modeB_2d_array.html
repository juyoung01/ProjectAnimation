Mode B in 2D — a square array of double-hinge octahedral cages

The adopted unit: six hubs at the octahedron vertices, two hinges per edge, each edge a chain hub–[arm p]–H1–[bar q]–H2–[arm p]–hub. All six hubs turn the same way, so the symmetry runs Oh → O. Here that cage is tiled by fusing antipodal corners. The ±x and ±y corners carry the sheet; the ±z corners stay free, which is what a third dimension would use.

Why the shared hubs rotate together

This is a rotation-only model. Each fused corner is represented by one physical hub and one spatial rotation matrix. Every arm incident on that corner is transformed by that same matrix. The purple connector between the two hinges may telescope during the sweep; its length is not a constraint.

J = −σaσā = −1  ·  true 90° square lattice, |t| = 2R  ·  checkerboard ordering

All six hubs share σ = +1 — that is what the second hinge buys — so an antipodal fusion gives J = −1 and neighbouring cages must sit in opposite states. The square lattice has only 4-cycles, so ∏J = +1 and the sheet can never be frustrated. One cage forces every other.

Through the sweep the corner welds never break (mismatch stays at 0.00e+00 from s = +1 to s = −1). The blue tick on each fusion shows the shared hub orientation. Because antipodal local axes point in opposite directions, neighbouring cages use opposite signed angles: R(−n,−θ) = R(n,θ). Thus both sides execute exactly the same spatial rotation.

Naming, since it was muddled earlier. In this project Mode A / B / C = one / two / four hinges per edge (modeB_protein_transistor.md §3). This page is the real Mode B. The companion page modeA_3d_array.html is Mode A — one hinge per edge, even prisms, stacked 3×3×3.

Scope. Kinematic rotation model with welded rigid hubs and length-compliant (telescoping or elastic) connectors. Energies, forces and steric overlap between non-bonded cages are not checked.
